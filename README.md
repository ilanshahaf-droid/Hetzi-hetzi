# חצי חצי – הוצאות הילדים

## הקמה
1. ב-Supabase: SQL Editor ← להריץ את `schema.sql`.
2. ב-Supabase: Authentication ← URL Configuration ← להגדיר את כתובת ה-GitHub Pages כ-Site URL
   (וגם להוסיף אותה ל-Redirect URLs), כדי שקישורי אימות ואיפוס סיסמה יחזרו לאפליקציה.
3. למלא את `config.js` ב-Project URL וב-anon public key (Project Settings ← API).
4. להעלות את כל הקבצים לשורש ריפו ב-GitHub ולהפעיל GitHub Pages.
5. להיכנס מהטלפון, להירשם, לאשר את המייל, ולהוסיף למסך הבית.

## ייבוא ספטמבר 2026
בחודש ספטמבר, כשאין עדיין רישומים, מופיע כפתור "ייבוא ספטמבר מהאקסל".
כל השורות נרשמות בתאריך 1.9.2026. אפשר לערוך תאריך לכל שורה בלחיצה עליה.

## עדכון גרסה
אחרי שינוי בקבצים, להעלות את המספר ב-`CACHE` בקובץ `sw.js` (למשל hetzi-v2).
